### 1. 一层循环
1.  列出循环次数 t 及每轮循环 i 的变化
2. 找到 t 与 i 之间的关系
3. 确定循环停止条件
4. 联立两式解方程

- 例：
```c++
int i=0;
while(n>=(x+1)*(x+1));
x=x+1;
```

|   |   |   |   |   |
|---|---|---|---|---|
|t|0|1|2|3|
|x|0|1|2|3|
|t = x               (1)|   
|n = (x+1)^2    (2)| 
|联立(1),(2)式|   
|t = n^1/2|   
- |T = O(n^1/2)|
